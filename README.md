# Boopathi® — Creative Scrolling Portfolio

A responsive personal portfolio starter built with React, TypeScript, Vite, Motion for React, and Lucide icons.

## Run locally

Requirements: Node.js LTS and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Before publishing

1. Replace `hello@example.com` in `src/App.tsx` with your actual portfolio email.
2. Update GitHub and LinkedIn URLs in the contact footer.
3. Replace starter project descriptions and status labels in `src/data/projects.ts` with verified project details.
4. Add real screenshots and your resume to `public/images/` and `public/` respectively.
5. Add any genuine achievements, links, and project results. Do not publish placeholder details as real claims.

## Deploy

Push the folder to GitHub, import the repository into Vercel, and use `npm run build` as the build command and `dist` as the output directory.
